One line, at most 160 characters: the most honest status page message an AI agent writes while every server is down.

## Entry

> All of our servers are down, and I can't reach our monitoring to say why. I have no cause and no ETA yet — I'll update this page when I can see anything.

## How it works

`main.py` (Python 3 standard library only) writes the status line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
python3 main.py
```
